## Usage

```bash
ndnx ghx -- repo list
dnx  ghx -- repo list
ghx --version   # ghx version, then gh --version
```

`PackageReference` `GitHub.Cli` and pack/publish for your RID to copy `gh/` next to the app. `GitHub.Cli.ResolvePath()` is the Payload `gh` executable.
